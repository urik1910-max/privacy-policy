Политика конфиденциальности

Дата последнего обновления: 03.10.2026

1. Какие данные мы собираем

Приложение использует Threads API для публикации постов и ответов на комментарии от имени владельца аккаунта. Приложение обрабатывает только данные, предоставленные через официальный Threads API: идентификаторы постов, текст комментариев, имена пользователей, оставивших комментарии.

2. Как мы используем данные

Данные используются исключительно для автоматизации публикации контента и ответов на комментарии в рамках аккаунта владельца приложения. Данные не передаются третьим лицам и не используются в рекламных целях.

3. Хранение данных

Данные хранятся на сервере владельца приложения в течение времени, необходимого для работы сервиса, и не передаются сторонним организациям.

4. Контакты

По вопросам, связанным с обработкой данных, можно связаться через аккаунт Threads: @meliksa.ai
